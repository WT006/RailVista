# 风景优美铁路线清单（路线入库参考）

> 用途：为 RailVista 走廊库（`data/presets/corridors/`）持续补充"风景优美"的候选铁路线。
> 更新：2026-09-12 ｜ 整理方式：公开资料检索 + 常识性收录；风景候选已分 **第四～七期** 入库（见第 1 节 / 第 5 节）
> 已入库现状：**约 65 份走廊 JSON**（含早期精品走廊 + 丽香/昆丽 + 风景第四～七期）；观光小火车仍不入走廊库。

---

## 0. 入库字段速查（对照 corridor JSON）

| 字段 | 含义 | 备注 |
|---|---|---|
| `id` | 走廊唯一 ID（英文短横线） | 新线建议：拼音缩写，如 `zhangjihuai` |
| `name` | 中文线路名 | 与官方命名一致 |
| `source` | 几何来源 | `china-hsr-simulation/hsr-rails.geojson`（高铁）或 `osm`（普速/OSM 匹配） |
| `sourceNames` | 源数据中的线路名 | 供拼接复用 |
| `stationsHint` | 主要经停站（数组，去"站"字） | **首末站必须是真实端点**；方向站（如杭州东/杭州南）同词干不同方位会被视为冲突站 |
| `railway` | `[lng, lat][]` 坐标折线 | 至少 2 点；直接放 JSON 即入库（目录 mtime 变更后自动重载） |

**匹配规则提醒**：
- 高铁走廊只对 **G/D/C 车次** 生效（`isHsrTrainCode` 显式拒绝 K/T/Z）。
- 普速风景线（青藏、拉林、宝成、湘黔等）**不能套高铁走廊**，需走 OSM 逐段生成，或像 Z8991 那样单独做 `*-railway.json` 预置资产。
- 跨线车次可用路网拼接（`corridorNetwork.ts`），多条走廊在共享枢纽自动连通。

## 2. 候选路线（国内，按区域分组）

> 标注"✅ 已入库"的为现状；其余为候选。`类型`：高铁=G/D/C 可套走廊；普速=需 OSM 预置/按需生成；观光=旅游专列/小火车（一般不入走廊库，仅作展示参考）。

### A. 高原与雪域（青藏高原 / 河西走廊）

#### A1. 青藏铁路（西宁—拉萨）✅ 已入库（qingzang / z8991）
- 类型：普速（世界海拔最高、线路最长高原铁路，1956 km）
- 沿途看点：青海湖、茶卡盐湖（侧线）、昆仑山、玉珠峰、可可西里无人区（藏羚羊）、沱沱河（长江源）、唐古拉山口（海拔 5072 m）、措那湖、羌塘草原、念青唐古拉山
- 备注：现有入库资产即本条，不再重复入库

#### A2. 拉林铁路（拉萨—林芝）✅ 已入库（lalin，锚点）
- 类型：普速（高原"绿巨人"复兴号动车组）；全长 435 km；2021-06-25 开通
- 建议 stationsHint：拉萨、贡嘎、扎囊、山南、桑日、加查、朗县、米林、岗嘎、林芝
- 沿途看点：雅鲁藏布江深切峡谷、"雪域江南"藏东南风光、雪山圣湖、森林湿地；每年 3-4 月"坐着火车看桃花"（林芝桃花节）
- 入库建议：普速线，仿 Z8991 做预置 `*-railway.json`（OSM），或运行时 OSM 逐段生成

#### A3. 拉日铁路（拉萨—日喀则）✅ 已入库（lari，OSM）
- 类型：普速；全长约 253 km；2014 年开通
- 建议 stationsHint：拉萨、协荣、曲水、尼木、仁布、日喀则
- 沿途看点：雅鲁藏布江河谷、藏南田园、羊卓雍措方向远眺、珠峰方向（日喀则转汽车）
- 入库建议：普速线，OSM

#### A4. 川青铁路（成都—西宁，成兰铁路更名）✅ 已入库（chuanqing，已开通段锚点）
- 类型：高铁/动车（设计 200 km/h，部分路段更高）；全长约 836 km；成都东—黄胜关段 2024-08-30 全线通车（镇江关—黄胜关为最后一段），成都东→黄龙九寨最快 99 分钟
- 建议 stationsHint（已开通段）：成都东、青白江东、三星堆、什邡西、绵竹南、安州、高川、茂县、镇江关、松潘、黄龙九寨、黄胜关
- 沿途看点：成都平原古蜀文明（三星堆）、岷江峡谷、高原羌藏秘境、松潘草原、黄龙钙华彩池、九寨沟（黄龙九寨站距黄龙 26km/九寨沟 100km，有景区接驳）；2026-08 "川青旅游专线"主题列车开行
- 入库建议：高铁走廊，G/C 车次可用；风景顶级、热度高，**高优先**

#### A5. 兰新高铁（兰州—乌鲁木齐）✅ 已入库（lanxin，OSM）
- 类型：高铁（世界一次性建成里程最长高铁之一，1776 km；2014 年开通）
- 建议 stationsHint：兰州西、西宁、门源、民乐、张掖西、临泽南、高台南、清水北、酒泉南、嘉峪关南、玉门、柳园南、哈密、吐鲁番北、乌鲁木齐
- 沿途看点：青海门源 60 万亩油菜花海（7 月盛花期，西宁—门源动车仅约 38 分钟）、祁连雪山、河西走廊戈壁、张掖丹霞方向、嘉峪关长城、哈密绿洲、吐鲁番火焰山
- 入库建议：高铁走廊，**高优先**（花海列车热点）

#### A6. 兰新铁路（普速老线，兰州—乌鲁木齐）
- 类型：普速；约 1903 km
- 沿途看点：河西走廊（武威、张掖、酒泉、嘉峪关）、戈壁绿洲、哈密、吐鲁番、天山
- 入库建议：普速线，OSM（与兰新高铁平行，可二选一）

#### A7. 敦格铁路（敦煌—格尔木，"大漠新丝路"）✅ 已入库（dunge，锚点）
- 类型：普速（单线，设计 120 km/h）；约 509-617 km（各口径不一）；2019 年 12 月全线开通
- 建议 stationsHint：敦煌、阿克塞、肃北、马海、鱼卡、大柴旦、饮马峡、格尔木
- 沿途看点：敦煌莫高窟、雅丹地貌（"地球上最像火星"）、透明梦柯冰川方向、祁连山、当金山、柴达木盆地盐湖（翡翠湖、察尔汗盐湖方向）、大漠戈壁（冬季落雪"水墨画"奇观）
- 入库建议：普速线，OSM；沿线国家级景区 14 处，**高优先**

#### A8. 格库铁路（格尔木—库尔勒）✅ 已入库（geku，锚点）
- 类型：普速/客货共线；约 1213 km；2020 年开通
- 建议 stationsHint：格尔木、茫崖（花土沟）、若羌、尉犁、库尔勒
- 沿途看点：柴达木盆地盐湖群、阿尔金山、罗布泊边缘、塔克拉玛干沙漠南缘、台特玛湖

## 5. 入库操作流程（对照代码）

### 5.1 风景线分期重建（推荐）

```bash
node scripts/build-phase4-scenic-corridors.mjs   # hsr + OSM relation 精确轨
node scripts/build-phase5-scenic-corridors.mjs   # 普速 OSM relation
node scripts/build-phase6-scenic-anchors.mjs     # 无 relation 时锚点稠密折线
node scripts/verify-scenic-phases.mjs            # 长度门禁
node scripts/seed-missing-stations-geo.mjs       # 仅补缺站坐标（不覆盖已有）
```

单条 OSM：`node scripts/build-corridor-from-osm-relation.mjs <relationId> <id> --name … --from lng,lat --to lng,lat --hint a,b,c`

### 5.2 通用步骤

1. **准备坐标**：高铁优先 `_hsr-rails.geojson`；否则 Wikidata P402 → OSM relation；再不行锚点 densify。
2. **写走廊 JSON**：`data/presets/corridors/<id>.json`；`stationsHint` 首末必须是真实端点。
3. **自动生效**：`corridors.ts` 按目录 mtime 热加载。
4. **验证**：`verify-scenic-phases.mjs` + `matchCorridor(..., { trainCode: 'G…' })`；K/T/Z 不得命中高铁走廊。
5. **注意**：全量 `seed-corridor-stations-geo.mjs` 可能把枢纽纠偏飞，风景期只用 `seed-missing-stations-geo.mjs`。锚点线 `source: anchors` 几何为示意，后续有 OSM 应覆盖升级。
