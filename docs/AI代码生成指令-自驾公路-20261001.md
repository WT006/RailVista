## 第一部分 · 项目上下文（AI 必读，勿略过）

你是 RailVista 项目的协作开发工程师。现在要开发**全新功能模块「万里路书 · 精品自驾公路」**。

### 项目现状

- 仓库：`github.com/WT006/RailVista`（SSH）｜当前协作分支：`heyworldchannel-20261001`
- 技术栈：Vue 3 + Vite + TypeScript（`apps/web`）、Hono 后端（`apps/api`）、共享类型（`packages/shared`），pnpm monorepo
- 现有 4 个路由：`/` 选行程 → `/trip` 行程地图 → `/route/:corridorId` 线路详情 → `/atlas` 全国地图
- 现有资产：248 条铁路走廊（`data/presets/corridors/`）、432 处景点（`data/presets/scenic-spots.json`，v3 六维）、全国铁路路网（`data/rails/`）、77 个单测用例、前端 gzip ~129KB、**当前版本 0.2.6**

### 本次新增什么

一个**并列于铁路工具的全新自驾模块**，把全国 G（国道）／S（省道）／县道乡道连成自驾公路网，产出 12 条国家级主干线 + N 条省级精品线，每条线做成可翻阅的「路书」，并在行驶中提供四大能力：

1. **小确幸雷达** —— 基于 GPS 位置 + 行驶方向 + 车速，计算前方点位并推送
2. **公路故事音频** —— 进入某段公路自动播放背景故事（TTS 兜底）
3. **轨迹自动记录** —— 只存关键点（起点/终点/停留/打卡），省电省流量，结束自动生成路书
4. **车速感知提醒** —— 景观路段减速、弯道/海拔/落石安全提醒

### 政策依据（真实，勿篡改）

交通运输部《精品自驾旅游公路实施方案》（**交公路发〔2026〕100 号**，2026-08-17 发布）：「1+N」体系，**三环、四横、五纵**主骨架，总里程约 **6 万公里**，**以普通国道为主体**。

官方 12 条线路名称（**必须原样使用，不得改名**）：

| 类别 | 线路 |
|---|---|
| 三环 | 沿边沿海环线、首都都市圈环线、青甘环线 |
| 四横 | 长城文化、黄河文化、长江文化、西部雪域天路 |
| 五纵 | 大运河文化、华东世界遗产、中部锦绣山岳、长征文化、古道秘境 |

**技术要点**
- Overpass 查询模板：
  ```
  [out:json][timeout:180];
  (
    way["highway"~"^(motorway|trunk|primary|secondary|tertiary)$"]["ref"="G318"]({bbox});
  );
  out geom;
  ```
- 等级映射：`G`+1~3位 → `G`；`G`+4位 → `E`；`S` → `S`；`X` → `X`；`Y`/`C` → `Y`/`C`
- 按省份 bbox 分片，避免超时
- 结果落盘缓存到 `data/cache/drive/ways/<ref>.json`，**勿重复抓取**

#### 任务 M0-2 · 端点成链

```
任务：把离散 ways 串成一条连续折线
① 文件与函数：
   apps/api/src/services/roadNetwork.ts
     - chainWays(ways: RoadWay[], opts?: { toleranceM?: number }): ChainResult
   ChainResult = { geometry: [number,number][], gaps: Gap[], usedWayIds: number[] }
   Gap = { atIndex: number, from: [number,number], to: [number,number], distM: number }
② 验收命令：
   pnpm --filter @railvista/api exec tsx scripts/probe-chain.mjs G318
③ 预期输出：
   ways=1247  chained=1247  gaps=0
   chainLen=2156.3km  (公开里程 2142km, 偏差 0.7%)
   OK
④ 禁止以 tsc/build/单测替代端到端验收，交付必须粘贴实测输出
```

**算法要求**
1. 端点坐标量化到 1e-5（约 1m）建哈希，统计度数
2. 度为 1 的端点作链头；从链头出发，每次取距离 < `toleranceM`（默认 300m）的最近未访问 way，必要时反转 way 内部点序
3. 断开处（>300m）写入 `gaps`，**绝不静默跳过**
4. 环线（无度为 1 的端点）时从任意 way 出发，首尾相接即闭合

**雷达算法硬规则（需求方明确，不得偏离）**
```
speed > 80 km/h → 只推 worthSlowDown=true 的点位（"值得减速"）
40 ≤ speed ≤ 80 → worthSlowDown 或 canPark 都推
speed < 40 km/h → 只推 canPark=true 的点位（"可以停车"）
```
- `lookahead = clamp(speedKmh * 0.05, 3, 15)` km
- 高速时 `worthSlowDown` 优先于距离排序（否则普通点会挤掉"错过可惜"的点）
- 卡片文案格式：`前方 3.2 公里・小确幸：无人雅丹观景点`
- 强提醒：距离 ≤ `notifyM`（默认 500m）时 `notify=true`
- `missed`：身后 0~1km 内的 `worthSlowDown` 点，提示"你刚错过"
- **必须在前端本地计算，禁止网络往返**（隧道无信号场景）

## 第五部分 · 常见错误与防坑清单

| 坑 | 表现 | 预防 |
|---|---|---|
| **遍历目录生成列表** | 冷启动慢、构建失败 | 强制 `_index.json` |
| **geometry 进主 bundle** | gzip 暴涨到 500KB+ | 独立接口 + 按需 import |
| **雷达走接口** | 隧道里卡死 | 纯前端计算，零依赖 |
| **改了 types.ts 现有字段** | 铁路侧编译爆炸 | 只追加，不改 |
| **忘了 bump 版本** | CHANGELOG 与界面对不上 | 提交前检查 4 处 |
| **gap 静默跳过** | 线路莫名断开几百公里 | gap 报告强制人工复核 |
| **左右侧写死** | 反向行驶时左右颠倒 | 运行时叉积计算 |
| **小确幸坐标不贴线** | 里程桩对不上、推送错位 | 校验 <300m 门禁 |
| **package 逻辑里 import vue** | 鸿蒙端无法复用 | 零框架依赖自检 |
| **车速阈值写反** | 高速推了"可以停车"的点 | 单测覆盖三档 |
| **省道/县道编号跨省重复** | S101 在多省冲突，索引互相覆盖 | 主键必须 `省:编号`；国道才用纯 `ref` |
| **G+4位误判为普通国道** | G5611 被当国道统计 | G+1~3 位=普通国道，G+4 位=国家高速 |
| **未命中几何的条目被丢弃** | 覆盖率虚高、用户查到却画不出 | 写入 `_missing.json`，UI 标注「暂无走向数据」 |
| **全国索引一次性全量加载** | 首屏卡死 | 按省分片，首屏只加载当前省（~250KB） |
| **几何进主 bundle** | gzip 暴涨 | LOD 按需加载 + 持久化缓存 |
