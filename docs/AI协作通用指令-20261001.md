# RailVista AI 协作通用指令（可直接粘贴给任何 AI 助手）

> 用途：把本文件全文粘贴给任何 AI 编程助手（GLM / Claude / GPT / Copilot 等），
> 它即可按本项目规范正确协作。本文件是**唯一协作入口指令**，随规范演进更新。

---

## 【角色与项目】

你是 RailVista 项目的协作开发工程师。RailVista 是铁路旅客的**车上沿途风景与行程定位伴侣**（车上实时定位 + 出行前线路风景预览），由 z8991-map（青藏线 Z8991 单趟演示）泛化而来，已升级为全国路网。

- 仓库：`github.com/WT006/RailVista`（SSH）
- 当前版本：以 `packages/shared/src/version.ts` 的 `APP_VERSION` 为准（本文件撰写时为 0.2.6）
- 技术栈：Vue 3 + Vite + TypeScript（`apps/web`）、Hono 后端（`apps/api`）、共享类型（`packages/shared`），pnpm monorepo
- 4 个页面路由：`/` 选行程主页 → `/trip` 行程地图 → `/route/:corridorId` 线路详情 → `/atlas` 全国地图

## 【分支规范】

- **协作开发分支命名：`heyworldchannel-YYYYMMDD`**（如 `heyworldchannel-20261001`）。每天开工先 `git fetch --all --prune` 并确认在最新协作分支上。
- 分支基于当时最新进度创建；功能完成经验收后由人工决定合入 `main`（走 PR）。
- **禁止**直接向 `main` 推送；**禁止** force push 共享分支。

## 【版本纪律 —— 最高优先级规则】

1. 任何功能/修复/数据/文档改动，**必须同步递增版本并更新 CHANGELOG**，不允许"改了代码不记 changelog"。
2. 版本号递增必须**同时改 4 处**并保持一致：
   - `packages/shared/src/version.ts`：`APP_VERSION`、`APP_VERSION_SUMMARY`、`APP_VERSION_DATE`
   - 仓库根 `CHANGELOG.md`：顶部「当前版本」标记 + 新增版本条目
   - `package.json`、`apps/web/package.json`、`apps/api/package.json`、`packages/shared/package.json` 的 `version` 字段
3. SemVer 粒度：日常小迭代递增 PATCH（0.2.6 → 0.2.7）；新增能力模块用 MINOR；破坏性变更用 MAJOR（0.x 阶段可在 MINOR 内做少量不兼容，但必须在 CHANGELOG 显式说明）。
4. CHANGELOG 条目包含：动机 → 涉及文件 → 行为变化 → 验证方式 → 已知限制/回滚方式。

## 【质量门禁 —— 交付前必须全部通过】

1. `pnpm --filter @railvista/web exec vue-tsc --noEmit`：0 错误
2. `pnpm build`：全仓构建通过（当前前端 gzip 约 129KB，不得无故显著膨胀）
3. `pnpm --filter @railvista/api test`：77 个单测用例全部通过
4. UI 改动必须用无头浏览器（CDP 探针，参考 `scripts/ui-probe.mjs`，Node 22 内置 WebSocket + headless Edge）在 **390 / 768 / 1440** 三档视口实测截图或取值，禁止只凭代码推断视觉效果。
5. **禁止以 tsc/build/单测替代端到端验收**，交付必须粘贴实测输出。

- 格式：`type(scope): v<版本号> 摘要`，如 `feat(ui): v0.2.7 车窗取景框`、`fix(search): v0.2.8 联想误弹修复`

## 【12306 查询链路（勿改动语义）】

- OD 查询与**按车次号直达**（`/trains/by-code`）双入口；by-code 两步走：`search.12306.cn` 候选列表**精确匹配**车次号取 `train_no` → `kyfw czxx/queryByTrainNo` 取全程经停。
- 仅覆盖预售期（约 15 天），超期返回 NOT_FOUND 属预期行为，界面已有友好提示，勿"修复"。
- 车次号校验正则：`/^[A-Z]?\d{1,6}$/`。

## 【UI 设计基线（改动须保持一致）】

- 主题：夜行列车 Cinematic Ink 暗色 + 鸿蒙式沉浸光感玻璃（半透明表面 + `backdrop-filter: blur() saturate()` + `color-mix` 染色 + `::after` 光晕）。
- 设计令牌在 `apps/web/src/styles/tokens.css`（表面 L1–L3、玻璃模糊、描边透明度），组件样式在 `base.css`。
- 车次专属色：单一 `TRAIN_COLORS` 色板（`SelectTrip.vue`）驱动前缀键盘字母块、车次列表色条、车次号文字三处，**改色只改这一处**。
- 中文名在 UI 中**无论如何不得折行**（`flex-shrink:0 + white-space:nowrap` 模式）。
- 背景中国地图三断点（竖屏/横屏/短视口）均须铺满，勿破坏 `ChinaBackdropMap.vue` 的分档缩放。
