# 排行榜榜单切换交互修复（2026-10-01）

## 问题现象

主页「中国最美铁路」排行榜模块（`apps/web/src/components/rankings/RankingsSection.vue`）中，
切换不同榜单的胶囊 Tab 在侧栏窄宽度下**后面的榜单选不到**：

- Tab 区此前为单行横向滚动（`flex-wrap: nowrap` + `overflow-x: auto`），且滚动条被完全隐藏
  （`scrollbar-width: none` + `::-webkit-scrollbar { display: none }`）；
- 4 个榜单标题较长（如「十大最受欢迎铁路旅游线路」），窄侧栏下后面的胶囊被截断在可视区外；
- 无任何滚动提示（无渐变遮罩、无箭头），用户不知道可以横向滚动，也无法拖动隐藏的滚动条 → 交互死角。

### 次要隐患

- `.rankings__tab::after` 热区伪元素左右各扩 4px（`--space-1`），与 `gap: 8px`（`--space-2`）处于临界；
  折行/溢出场景下热区会覆盖相邻 Tab 边缘，造成点击误触遮挡；
- 热区纵向溢出容器，配合 `overflow-x: auto`（overflow-y 计算为 auto）可能引发容器意外滚动。

## 解决方案

改为**折行排列，全部 Tab 直接可见、直接可点**，彻底消除滚动死角：

1. `.rankings__tabs`：`flex-wrap: nowrap` → `flex-wrap: wrap`，移除 `overflow-x: auto`、
   `scrollbar-width: none`、`::-webkit-scrollbar` 隐藏规则及 `padding: 2px / margin: -2px` 滚动边界 hack；
2. `.rankings__tab`：删除 `::after` 热区伪元素，触控热区改由真实盒子的
   `min-height: 32px` + `display: inline-flex; align-items: center` +
   `padding: var(--space-1) var(--space-3)` 保证 —— 真实盒子由 flex 布局保证互不重叠，交互绝对可靠；
3. 保留 `flex-shrink: 0`，胶囊不压缩变形、文字完整展示。

### 取舍说明

此前的单行设计意图是"接近 HarmonyOS 分段控件、避免折行观感凌乱"，但隐藏滚动条导致功能不可用，
**可用性优先于观感**：折行后每个胶囊完整可见可点，配合紧凑胶囊样式保持整齐。

## 验证

- `pnpm --filter @railvista/web run build`（`vue-tsc --noEmit` + `vite build`）全部通过；
- 手工验证路径：主页侧栏 → 榜单模块，4 个榜单胶囊应全部直接可见，逐个点击均可正常切换。
