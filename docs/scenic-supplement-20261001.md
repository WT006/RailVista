### 0.2 三类数据标记

| 标记 | 含义 | 可信度 |
|---|---|---|
| **【实测】** | 由走廊几何直接计算（里程、离轨距离、左右侧、覆盖度） | 高，可复算 |
| **【候选】** | 名称/坐标由本批提出，坐标为知识库初值，尚未取得 S/A 级坐标真值 | 中，**入库前须 GCJ02→WGS84 终核 + 补源** |
| **【复核】** | 几何/坐标判定异常或近邻重复 | **禁止直接入库** |

### 0.3 全局硬规则（沿用 v3 与上一批约定）

1. 坐标系一律 WGS84；高德/腾讯/百度坐标须转换并在 `sources[].note` 注明。
2. `verification.status` 未达 `verified` 的条目只进 staging，不写主库。
3. 来源门槛：≥1 条 S/A 级 + 1 条独立第二源。
4. 地图 pin = 景观本体真值，不得用"最佳观赏点"或"最近车站"当坐标。
5. `side` 只写 `left/right/both` + `sideRefDirection: line_forward`，运行时按车次方向换算。

## 4. 左右侧（side）实算说明
