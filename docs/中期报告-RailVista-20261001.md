## 一、项目定位回顾

> **RailVista 是铁路旅客的「车上沿途风景与行程定位伴侣」**，同时支持出行前预览线路与风景。

核心价值优先级：

1. **核心（A）**：上车打开 → 知道现在在哪 → 下一处风景 / 下一站是什么
2. **兼得（B）**：出行前选车次 → 预览全程地图与风景列表

基于 z8991-map（青藏线 Z8991 单趟演示项目）泛化而来，已实现**从单趟列车到全国路网**的升级。

## 四、技术架构与工程质量

### 4.1 架构

```
RailVista (pnpm monorepo)
├── apps/web        Vue 3 + Vite 6 + TS（4 页面、9 组件、3 composables）
├── apps/api        Hono 后端（5 组路由、28 个服务模块）
└── packages/shared 共享类型与版本常量
```

- **前端页面**：`/` 选行程（主页）→ `/trip` 行程地图 → `/route/:id` 线路详情 → `/atlas` 全国地图
- **API 路由**：trains（车次/经停/by-code）、stations（站名/坐标）、railGeometry（钢轨折线）、atlas（全国数据）、presets（预置内容）
- **关键服务**：12306 代理（OD + 车次号双链路）、Overpass 竞速、精准路线缓存/预热、走廊网络、景点检索、 geocode、单实例锁、版本指纹
