## 三、本轮踩到的坑（**阶段 3 必须照做**）

### 3.1 `roadClass` 只有 8 个枚举值 —— 本轮最大的一次教训

`scripts/build-roadbook-index.mjs:51`：
```
国道  高速  省道  县道  乡道  景区公路  城市道路  步道
```
**它是「行政等级」，不是道路用途/环境属性。** 写「边防公路」「林区道路」「林区公路」「山区公路」→ 直接 ERROR。
本轮 G331 那条因此吃了 **9 条 ERROR**。

根因：**主理人派单时凭感觉列了一份非法清单**，工程师照抄。纠正方式：
环境/用途描述放进 `note` 或 `via`，等级字段只填等级。

> ⚠️ 派单前先 `grep -n "roadClass" scripts/build-roadbook-index.mjs` 核枚举，别凭记忆。

### 3.2 文案杂字：闸门绿 ≠ 文案干净

生成式写入会在中文字段里混入外语碎片。三个特点：
1. JSON 依然合法，不报错；
2. **闸门 `scanGarbage` 拦不住** —— 它只管占位符、块级标签、日文假名、西里尔字母 + 6 个固定生造词，
   纯拉丁散文（`fireworks` / `but` / `hill`）一条不过问；
3. 只会安静留在给读者看的文案里。

本轮实例：
- 吉黑文件曾出现 5 处西里尔字母（`турист ticket` / `Бай 山` / `каньон` / `рассказ exposition`）
- 漠河北极村整条崩坏：**85 处**杂字，`hmm` 重复几十次 + `esthmm`/`soumming`/`bmmm`/`Patras`/`dirigendo`
  → **判据：`hmm` 这类占位音反复出现 = 生成 token 碎裂，必须整条重写，不能逐处替换**

**已固化工具**：`scripts/roadbook-scan-garbage.mjs`，**每个批次必跑**。
```bash
node scripts/roadbook-scan-garbage.mjs                    # 全库
node scripts/roadbook-scan-garbage.mjs <file.json>        # 单文件
node scripts/roadbook-scan-garbage.mjs --since=2026-10-09 # 只扫某天写入的
```

### 3.3 「算出来的数」优于「参考值」，但不能反过来凑数

本轮四次判定，标准完全一致：

| 案例 | 数从哪来 | 裁决 |
|---|---|---|
| 五台山 200 → 288km | 忻州↔台怀实际路况分段相加 | **采纳** |
| 克什克腾 560 → 980km | 赤峰↔经棚 + 经棚↔石阵 + 经棚↔乌兰布统 | **采纳** |
| G331 3180 → 3815km | 13 段 haversine 直线 2620 × 地形系数 1.46 | **采纳** |
| 河北想 18 → 26km 只为凑 Σseg 相等 | 从结果倒推 | **否决** |

> **判据：数是算出来的（有分段依据）可接受；数是凑出来的（为对齐目标值而调）必须否决。**

### 3.4 验收标准不要先松后紧

主理人曾对**已归档**的河北两条追加「Σseg 零误差」要求（原始口径是偏差 ≤25%），
属于先验收后加码，已撤回。**已归档内容不追溯**，新标准只对后续批次生效。
基线口径：`Σplan === totalKm`（硬要求）+ `Σseg` 偏差 ≤25% + `mileageNote` 说明差额去向。

### 3.5 换人接手同一文件前，先给前一位发收工确认

本轮有 3 个文件被两位工程师接力写入。必须**先明确让前一位收工**，否则并发 Edit 会互相覆盖。

### 3.6 顶层 `note` 里的路线条数会静默变错

`note` 里常写「河北线路书 **5** 条」这类句子，追加后如不更新就变成错误陈述。
本轮两处都撞到（河北 5→7、山西 6→8）。`roadbook-scan-garbage.mjs` 已内置这条计数校验。

### 3.7 主理人给错的两条业务信息（工程师没盲从，是对的）

- **阿尔山站**：主理人写「中东铁路时期小型站房」——**错**。中东铁路是滨洲/滨绥线（满洲里—哈尔滨—绥芬河），
  不经过阿尔山。阿尔山站是**白阿铁路（白城—阿尔山）终点**。工程师保持了保守写法（以现场说明牌为准）。
- **G331 参考里程 2800~3200**：主理人拍的框，实际 3815。工程师按 haversine 反算后拒绝迁就。

> 这印证既有纪律：**发现「缺陷」先问——是真缺陷，还是我上一轮引入的？**
