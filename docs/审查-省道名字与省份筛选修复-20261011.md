# 审查与修复报告：省道名字错乱 + 省份筛选失效

> 日期：2026-10-11
> 分支：`heyworldchannel-20261011`
> 结论先行：**两个问题均已修复并验证。名字错乱根因是 deriveFromNet 的"取最长 name"策略，已改为"频次多数原则 + 三类清洗 + 省后缀"；筛选失效根因是服务端先截断后无法按省过滤、前端未监听选省变化，已改为"服务端截断前按省过滤 + 前端选省联动重新请求"。**

---

## 1. 问题

用户反馈：① 省道的省份筛选功能用不了；② 省道名字很多错乱；③ 要求对所有省道全部审查名字，名字加省份标识。

### 1.1 省份筛选失效根因

- **服务端**（roadIndex.ts suggestPlacesOfKind）：road 搜索对全量索引打分后 `slice(0, limit)` 截断。S2 前缀查询命中数千条同分（85）条目（S2/S20/…/S299 × 各省），截断后被**一省碎片淹没**（实测 `S2` 返回 80 条中安徽占 66 条）；
- **前端**（DriveHome.vue）：只 `watch(codeQuery)`，**未监听 selectedProvince** ——用户选省后不重新请求，只在已被截断的 80 条里本地过滤，导致"选了省基本没结果"。

### 1.2 名字错乱根因

deriveFromNet 取 name 策略为**"取最长的 name"**（`w.name.length > e.name.length`），导致垃圾长名必然胜出。全量审查（新增 `scripts/audit-road-names.mjs`）发现五类错乱：

| 模式 | 数量（修复前） | 示例 |
|------|-------------:|------|
| C1 垃圾名（抓取噪声） | 1 | 江苏:Y1 name="20 m 经度：119.57纬度：31.55自然资源部 & NavInfo审图号：GS（2024）0568号地图纠错…东桥北路" |
| C2 同义反复 | 209 | 海南:S202 name="202 省道 - 202 Provincial Highway"、安徽:X15 name="X015" |
| C3 多语言混杂 | 3 | 新疆:S21 name="阿乌高速 - ئالتاي - ئۈرۈمچى يۇقىرى سۈرئەتلىك يولى" |
| C4 高速段名 | 1032 | 重庆:S2 name="沿江高速长寿支线"（省级高速挂 S 编号，真实情况，保留） |
| C6 空名 | 5382 | OSM 无 name（展示层用 ref + 省标识解决） |

## 2. 修复方案

### 2.1 名字审查与清洗（数据层，`scripts/build-road-index.mjs`）

deriveFromNet 重写 name 选择逻辑：

1. **可信路名过滤**（`plausibleRoadName`）：
   - 剔除 C1 垃圾名：含"经度：/纬度：/审图号/地图纠错/高清版/NavInfo/自然资源部/切换至传统版"特征；
   - 剔除 C2 同义反复：name 数字与 ref 相同且含"省道/Provincial/Hwy/Highway/国道"词，或纯编号名（"X015"/"S466"，展示层已有 ref，冗余或错标）；
2. **频次多数原则**（`pickBestName`）：同名 way 出现最多的胜出（"潘黑路"30 次胜过垃圾名 1 次）；平票时含中文的优先、更短的优先（短名多为核心路名）；
3. **省后缀**：全部省道/县乡道 name 统一加省标识 —— `潘黑路（安徽）`、`龙小线（广东）`、`半虎公路（河北）`；无 name 的条目展示层由 sub 补省标识；
4. PROVINCIAL_SEED 种子条目同样加后缀。

### 2.2 省份筛选修复（API + 前端）

- `apps/api/src/services/roadIndex.ts`：`suggestPlacesOfKind`/`suggestPlaces` 加 `province` 参数，road 分支**先按省过滤再打分**（截断之前）；sub 展示统一加省标识；排序改进——同分（前缀命中）时**短编号优先**（S2 < S20 < S201），避免截断淹没各省主编号；
- `apps/api/src/routes/drive.ts`：`/suggest` 读取 `province` query 参数透传；
- `apps/web/src/api/client.ts`：`suggestDrivePlaces` 加 `province` 参数；
- `apps/web/src/pages/DriveHome.vue`：新增 `watch(selectedProvince)` 联动重新请求（服务端截断前过滤），请求携带已选省。

- `GET /api/drive/suggest?q=S2&kind=road&limit=80&province=河北` → 79 条全部河北编号（"S2 · 河北 · 津宁高速（河北）"）✅

- 前端：选省按钮 → 重新请求 → 候选全为该省编号 ✅

1. C4 高速段名（1084 条）：省级高速（S2 沿江高速等）挂 S 编号属真实情况，保留；如需区分"省级高速 vs 普通省道"，可在索引层增加 subclass 字段；
2. C6 空名（5470 条）：OSM 无 name 的省道，展示名即编号 + 省标识（"S203 · 黑龙江"）；补全 name 需接官方省道名录或地名库反查；
3. C3 多语言残留 1 条：少数民族地区路名含维/藏语区段属真实情况，保留。
