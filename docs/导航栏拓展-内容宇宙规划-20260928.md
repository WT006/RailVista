# RailVista 导航栏拓展 · 内容宇宙规划

> 在现有「行程工具」之外，拓展一批**并列的大功能模块**，每个都能独立占据一个导航位。
> 命名统一走「万里路书」这种诗意家族风，把产品从工具升级为**铁路旅行内容宇宙**。
> 编制日期：2026-09-28 ｜ 基于 v0.1.3

---

## 一、命名理念：一个诗意家族

「万里路书」给人的感觉是——**有旅程感、有收藏感、有文人味**。整套模块沿用这个调性，
用 2~4 字的意象词命名，让导航栏本身就像一本目录：

| 模块名 | 意象 | 一句话定位 | 功能属性 |
|--------|------|-----------|---------|
| **万里路书** | 走过的路，成书 | 我的旅行记录与游记 | 记录 · 沉淀 |
| **山河图鉴** | 集齐山河 | 景点收集养成百科 | 收集 · 留存 |
| **车窗映画** | 一窗一世界 | 铁路风景影像中心 | 视频 · 种草 |
| **铁轨电台** | 闭眼听铁路 | 语音导览与声景 | 音频 · 陪伴 |
| **时光站台** | 线路的前世今生 | 铁路历史人文 | 深度 · 权威 |
| **风物集** | 下车尝一口远方 | 沿途美食风物玩法 | 本地 · 变现 |
| **星夜专列** | 夜航向星河 | 夜行与星空专题 | 场景 · 沉浸 |
| **同路人** | 鉄道上的相逢 | 旅伴与社区 | 社交 · 生态 |

> 备选名可替换：山河图鉴→「风景志」；车窗映画→「光影车厢」；铁轨电台→「声景列车」；
> 时光站台→「铁路记忆」；风物集→「沿途风物」；星夜专列→「夜航」；同路人→「旅伴」。

## 二、八大并列大功能详解

每个模块都标注了**复用的现有资产**（248 走廊 / 432 景点 / 六维 / solar / ETA / 暗色主题），
确保不是凭空造需求，而是把已有数据"换个形态再卖一次"。

### 1. 万里路书 · 我的旅行记录

**定位：** 每一次乘车，自动沉淀成一本可收藏、可分享、可导出的「路书」。

- **自动生成**：行程结束 → 路线图 + 时间轴 + 经过景点 + 打卡照片 + 随笔占位，一键成稿
- **编辑器**：图文混排、插入景点卡、标注「最佳一刻」、封面自选
- **导出**：长图 / PDF / 小红书图文 / 短视频脚本（对接剪映）
- **书架**：走过的线路按时间或地理排列，「已集 X 本路书 · Y 条线路 · Z 万公里」
- **博主示范**：视界hey world 精品路书置顶，用户可「复制同款行程」

**复用资产：** 行程时间轴、GPS 轨迹、景点序列、打卡、ETA
**博主价值：** 一次乘车 = 一条标准化内容，游记生产从「回家憋三天」变成「下车即成稿」

### 2. 山河图鉴 · 景点收集养成

**定位：** 把 432 → 5000+ 景点做成「收集图鉴」，去过点亮、没去种草。

- **图鉴卡**：每个景点一张卡（实拍图 / 六维标签 / 稀有度 / 最佳季节 / 资质荣誉）
- **点亮机制**：进入景点范围自动点亮，或上传照片手动点亮
- **多维浏览**：按六维 / 主题 / 线路 / 省份筛选，收集进度条
- **稀有与限定**：季节限定、夜行限定、「全网仅 X% 用户集齐」
- **待发现**：未点亮的灰色图鉴 = 探索冷门线路的钩子

**复用资产：** 六维分类、honors 资质、bestView 观赏时段、verification、/atlas 地图
**博主价值：** 收集机制是最强留存引擎；图鉴本身就是可售卖的内容素材库
**注意：** 与现有 /atlas「地图浏览」错位——atlas 是"看地图"，图鉴是"集卡片"，养成感完全不同

### 3. 车窗映画 · 影像中心

**定位：** 铁路风景的视频库，边看边种草，一键复刻同款行程。

- **内容组织**：按线路 / 景点 / 主题聚合短视频、Vlog、延时摄影、无人机航拍
- **可跳转**：视频内嵌「这是哪条线 / 哪个景点」→ 直达线路详情或加入行程
- **同款行程**：看完一键生成 OD + 车次 + 景点清单
- **双来源**：博主专区 + 用户投稿影像（审核后展示）

**复用资产：** corridorId 关联、线路详情页、景点库
**博主价值：** Vlog 分发主场，构成「视频 → 下载 App → 会员」转化漏斗的最顶端

### 4. 铁轨电台 · 音频中心

**定位：** 可以闭眼听的铁路——语音导览、环境声景、播客、有声故事。

- **景点导览**：博主真人录音 + TTS 兜底，接近景点自动播报
- **环境声景**：火车哐当、站台广播、隧道风声（白噪音 / 助眠 / 专注）
- **铁路播客**：时光站台内容的音频版，通勤/睡前场景
- **后台播放**：息屏续播，到站/到景点自动唤醒

**复用资产：** solar/ETA 触发引擎、景点故事卡、鸿蒙 Core Speech Kit
**博主价值：** 音频是低成本高粘性形态，一次录制长期复用，且天然适配鸿蒙后台能力

### 5. 时光站台 · 铁路历史人文

**定位：** 每条线路的「前世今生」，用深度内容树立专业权威人设。

- **百年铁路专题**：京张、滇越、滨洲、中东铁路、成昆…
- **史料呈现**：老照片、历史地图、工业遗产、废弃/停运线路
- **线路时间轴**：从动工修建到今天的高铁化
- **古今联动**：「坐这趟车，看这段历史」→ 关联现实车次与景点

**复用资产：** corridor 走廊数据、culture/history 六维景点
**博主价值：** 差异化深度内容，是出版《中国铁路风景图鉴》和接文旅局合作的素材底座

### 6. 风物集 · 沿途风物与下车玩

**定位：** 从「车上看」延伸到「下车玩」——站点周边的美食、特产、民宿、玩法。

- **风物卡**：每个经停站的地方美食、特产、3 小时 / 半日玩法
- **站停推荐**：「这站停 40 分钟，能下车吃什么」→ 基于 stopoverMin
- **住宿联动**：民宿 / 酒店联合推荐
- **季节风物**：赏花 / 赏雪 / 水果季 / 迁徙季

**复用资产：** stations-geo 坐标、经停站序列、stopoverMin 站停时长
**博主价值 + 商业：** 这是最自然的本地生活 / CPS 变现入口（酒店 8~15% 佣金、餐饮团购）

### 7. 星夜专列 · 夜间专题

**定位：** 夜行列车与星空夜景的沉浸式专题体验。

- **夜行精选**：Z/T 字头经典夜车 + 夜间可见景点（nightOnly）
- **星空提示**：结合 solar 模块的日照/月相，推荐观星时段与朝向
- **夜航模式**：暗色沉浸 UI + 助眠声景 + 到站温柔唤醒
- **城市夜景走廊**：夜间穿城的高架/海岸线视角

**复用资产：** nightOnly 字段、solar.ts 太阳/月相计算、ETA night 标记、Cinematic Ink 暗色主题
**博主价值：** 独特细分场景，暗色主题已有视觉基础，出片率高、社交传播性强

### 8. 同路人 · 旅伴社区

**定位：** 铁路旅行者的社区——同车、话题、打卡广场、博主频道。

- **同车旅伴**：同车次 + 同区间的用户可见 → 临时聊天室（行程结束归档）
- **打卡广场 / 话题圈**：UGC 内容沉淀与互动
- **博主频道 + 创作者入驻**：视界hey world 认证频道，其他博主可开专辑
- **结伴约拍**：摄影同好组队

**复用资产：** 车次 + OD 匹配、打卡体系、UGC 审核流
**博主价值：** 社区沉淀用户资产，是从「个人 App」走向「平台」的关键一步

## 三、导航栏架构建议

移动端底部导航最多 5 个位，8 个模块不能全塞进去。建议**「2 个晋升 + 1 个聚合」**：

```
┌──────────────────────────────────────────────────────────┐
│                     底部主导航（5 Tab）                     │
├──────────┬──────────┬──────────┬──────────┬──────────────┤
│  行程     │  发现     │  路书     │  图鉴     │   我的        │
│ (工具核心)│ (内容宇宙)│(万里路书) │(山河图鉴) │ (账号/成就)   │
└──────────┴──────────┴──────────┴──────────┴──────────────┘
     │           │
     │           └──► 发现页 = 宫格聚合其余 6 大模块：
     │                 车窗映画 · 铁轨电台 · 时光站台
     │                 风物集   · 星夜专列 · 同路人
     │                 （+ 远方规划/AI行程 作为工具入口）
     │
     └──► 现有：选车次 → 行程地图 → 景点定位 → 精准路线
```

**为什么路书和图鉴晋升到一级 Tab：**

- 二者是**与工具最并列**的「用户资产」——工具解决"现在在哪"，路书解决"我去过哪"，图鉴解决"我集齐了啥"
- 都是**高频回访 + 强留存**入口，值得占独立 Tab
- 其余 6 个偏「内容消费」，聚合进「发现」宫格，用诗意命名做成一个可逛的杂志目录

**发现页宫格视觉：** 每格用模块名 + 一句意象文案 + 主题色图标，营造"翻开一本铁路旅行杂志"的感觉。

## 四、优先级与依赖

| 梯队 | 模块 | 理由 | 依赖 |
|------|------|------|------|
| **第一梯队**（先做） | 万里路书、山河图鉴、车窗映画 | 复用现有数据最多、博主最急需、与工具最互补 | 需先有账号体系(P2-01) |
| **第二梯队** | 铁轨电台、风物集 | 音频低成本高粘性；风物集直接变现 | 音频需故事卡文案；风物需站点POI数据 |
| **第三梯队** | 时光站台、星夜专列 | 深度/差异化内容，塑造权威，但生产周期长 | 需人工内容积累 |
| **生态级** | 同路人 | 社区是平台化基础，但需先有用户规模 | 依赖前几个模块拉起 DAU |

**建议起步组合：** 账号体系 + 万里路书 + 山河图鉴（三件套），
让「工具 → 记录 → 收集」形成第一个闭环，再逐步铺开内容消费模块。

## 五、与商业变现的呼应

每个模块都天然挂接一条变现线（对应总路线图第五章）：

| 模块 | 变现接口 |
|------|---------|
| 万里路书 | 导出高清/去水印 = Pro 权益；路书模板付费 |
| 山河图鉴 | 稀有图鉴/限定卡片 = 会员解锁；实体徽章电商 |
| 车窗映画 | 会员专享 4K/无广告；博主付费专辑 |
| 铁轨电台 | 真人语音导览包付费（¥9~19/线路）|
| 时光站台 | 深度专题付费；出版/文旅局合作素材 |
| 风物集 | 酒店/餐饮 CPS 佣金（8~15%）— 最直接的现金流 |
| 星夜专列 | 会员专属夜航模式/星景预测 |
| 同路人 | 创作者专辑分成（平台抽 20~30%）|

## 六、一句话总结

> 现有 RailVista 解决的是**「我此刻在铁路的哪里」**；
> 这八大模块要解决的是**「我的铁路人生」**——
> 走过的（路书）、集齐的（图鉴）、看过的（映画）、听过的（电台）、
> 读懂的（时光）、尝过的（风物）、夜航的（星夜）、遇见的（同路人）。
