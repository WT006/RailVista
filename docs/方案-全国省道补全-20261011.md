# 方案与执行报告：全国省道（S）大量补全

> 日期：2026-10-11
> 结论先行：**省道此前在几何层、名录层、索引层三层全部缺失（S 编号 0 条）。本次通过三步管线一次性补全：省道几何 4273 条（39.6 万 km）、索引 14803 条（含省/县/乡道）、API 覆盖 100%。用户抽查的 S244/S336/S304/S316/S210/S203 全部可查。**

---

## 1. 问题

用户抽查全国省道发现大量缺失：S244、S336、S304、S316、S210、S203 等均查不到。

排查确认三层全缺：

| 层 | 位置 | 补全前状态 |
|----|------|-----------|
| 几何层 | `data/roads/geom/{省}_{S编号}.json` | **0 条**（仅国道/高速 568 个 G 文件） |
| 名录层 | `data/roads/authoritative/provincial.json` | 仅 12 条手工种子（PROVINCIAL_SEED：青海/四川/云南等路书走廊沿线） |
| 索引层 | `data/roads/index/provincial.json` | 仅 12 条 |

## 2. 根因

1. 索引构建脚本 `scripts/build-road-index.mjs` 的 `--from-net` 参数**从未被使用**——`deriveFromNet()`（L66-112）本可从分省 rvwn 要素库按 ref 标签聚合出全部省道/县乡道名录，但历史构建只传了 `--merge`，于是索引回落到 12 条种子；
2. 几何装配 `scripts/build-road-geom.mjs` 的 `--class provincial` 同样从未跑过（历史只跑了 national/expressway）；
3. 分省 rvwn 要素库（`data/roads/net/*.rvwn`，31 省）**本身已含省道 way**（rvwn.mjs `CLS_CODE` 含 `S: 2`，census 显示仅海南一省就有 1805 条省道 way / 41 个编号）——数据一直在库里，只差两步构建没执行。

## 3. 解决步骤（已执行）

```bash
# ① 装配省道几何（~2.5 分钟）
node scripts/build-road-geom.mjs --class provincial
#    → data/roads/geom/ 4273 条 S 省道文件（{省}_{S编号}.json）
#    → 报告 data/roads/reports/geometry-2026-10-11.json

# ② 从要素库派生名录 + 并入几何统计，重建索引（~2 分钟）
node scripts/build-road-index.mjs --from-net --merge
#    → index/provincial.json：12 → 14803 条（省道 4273 + 县道 5769 + 乡道等）
#    → 另回收规划名录之外的 G/E 编号 521 条（source=osm_only）

# ③ 重启 API 重载索引层
pnpm dev:api
```

## 5. 精度诚实边界

省道精度以 **C 级为主（4245/4257）**：OSM 中省道 ref 标签大量断续，同一编号被拆成多个不连通分量（多段 2325 条、去重段 3334）。这符合"如实输出、不猜不拼"的管线哲学——**几何是真实的，但完整性分级诚实标注为 C**。A/B 级提升需后续跑 `fill-road-gaps` 补洞管线（与国道 2026-10-02 精度提升同路径）。

## 6. 后续可选项

1. **省道精度提升**：对热门省道跑 `fill-road-gaps` / `repair-road-corridor`，把 C → A/B（建议只做路书走廊覆盖的热门省道）；
2. **省道名录去重校验**：跨省重复编号（如 S203 30 省）主键为 `省:编号`，无冲突；但同省可能出现 OSM 与官方编号不一致，可跑 `audit-road-network.mjs` 抽验；
3. **底图位图重渲染**：`build-drive-network-raster.mjs` 重跑后 `drive-network.png` 将包含省道（当前位图为构建期产物，未含本次新省道）；
4. **路书关联**：`data/presets/roadbooks/` 的 segments 可用省道编号（roadRefs）关联新增几何。

## 7. 一句话复现

> 以后任何时候省道/县乡道缺失，跑两条命令即可全量恢复：`node scripts/build-road-geom.mjs --class provincial && node scripts/build-road-index.mjs --from-net --merge`（前提：`data/cache/osm/*.pbf` 已由 `fetch-china-pbf.mjs` 下载）。
