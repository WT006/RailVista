## 三、改造内容（按主题）

### 3.1 导航体系（《底部页签》+《响应式应用架构》）
- **底部页签（<840px）**：24vp 图标 + 文字标签、选中品牌高亮 + 弹跳动效
  （BounceSymbolEffect 等效，--dur-base + 弹性曲线）、点击当前页签回滚页顶、
  56vp 高度（安全区另计）、上缘 1px 分割线、上方 16vp 渐变蒙层（与页面背景同色）、
  未选中弱化、按住态；中置运营项保留胶囊形态（图标居中、强调底）。
- **侧边 Tab（≥840px）**：新增 `AppSideNav`，导航项与图标继承底部页签；
  顶栏导航链接下线（`AppNavLinks.vue` 删除）；`--sidenav-w` 令牌统一驱动
  文档流页面（`.rv-page/.route-page/.drive-page` 让出左内边距）与全屏地图浮层
  （`.top-bar`、`.bottom-panel`、Atlas 控件、SpotApproachCard）的避让。
- 断点体系：系统档 599/600、839/840、1200；细调档白名单 380/480/560/960；
  消除 640/641/720/721 等非标断点（AtlasMap 的 JS 初始态同步 720→840）。

### 3.2 设计令牌（tokens.css）
- 新增：`--interactive-hover/pressed`（官方 5%/10% 白）、`--focus-ring`、`--hit-min`、
  材质高光（`--glow-*/--sheen-band`）、chrome 玻璃（`--glass-blur-chrome`）、
  底部渐变蒙层高度、`--sidenav-w`、地图浮层阴影族（`--elev-float* / --elev-up /
  --pin-shadow / --pin-rim / --surface-lift`）、地图标注字号（`--fs-annot*`）、
  氛围脉冲 `--dur-pulse=1600ms`、地图标注强调（`--map-amber* / --map-heat`）、
  纪念票主题金（`--ticket-gold*`）。
- 栅格 margins 对齐《布局基础》16/24/32；底栏高度 68→56。
- **旧令牌兼容别名区删除**（此前 437 处引用已全部迁移为语义令牌）。
- 数据语义色单一来源化：新增 `data/trainColors.ts`（自 SelectTrip 提取）、
  `data/atlasColors.ts`（来源色/描边/热力色阶/行程描边）；`roadColors.ts` 增补
  `ROAD_SHADOW_STROKE`。
- base.css 新增公共可达性工具：全局 `:focus-visible` 焦点环、`.rv-hit` 命中区扩展、
  `.rv-pressable` 按压态。
