## 五、验收基线

```
node scripts/roadbook-selfcheck.mjs <本批新文件…>     # 单文件自检，必须 0 error
pnpm.cmd roadbook:check                                # 全库，必须「✓ 全部校验通过（WARN 2 条 / 存量待治理 1 条）」
node scripts/roadbook-scan-garbage.mjs <文件>          # 乱码/占位符扫描
node scripts/roadbook-scan-content.mjs <文件>          # 内容红线扫描
```

**WARN 数不得因本轮增加**（基线 WARN 2 条 = 海拉尔 / 喀什 的 anchorCity 存量问题；
存量待治理 1 条 = 海拉尔）。这三条都是既有存量，不是本轮引入。
