# 一、总体结论

本次对清单 V2 全部正式收录点（271）、存疑点（77）、不予收录项（92）的地点信息进行核查，重点核对景点实际位置、所属线路、坐标（WGS84）与距线距离。绝大多数点位的线路归属与地理位置成立，但发现需处理的地点问题 16 项，其中：

1. 坐标偏移（硬伤）9 处：文档以精确坐标（未标“约”）给出，但与景点实际位置偏移 11～34 公里，远超文档自设的“约 ±1～2km”置信范围；

2. 方位 / 线路归属错误 4 处：巢湖岸别、潍河跨线归属、澜沧江铁路桥位置、拉法山车站名与海拔；

3. 距离 / 可见性失实 2 处：津秦高铁昌黎黄金海岸、野象谷段；

4. 同一线路拆分重复收录 1 处：哈大高铁与“沈大高铁”实为同一条线，大连段重复。

说明：文档中已标注“约 / 推断 / 存疑”的点位，其坐标粗略属预期，未计入问题；下列问题均针对以“确定口径”给出、但与事实不符的条目。

# 五、同一线路拆分 / 重复收录（1 处）

东北章节“1. 哈大高铁（哈尔滨—大连）”与“2. 沈大高铁（哈大高铁沈阳—大连段）”实为同一条线路（哈大高铁沈阳至大连段即俗称沈大段，并非独立线路）。其中哈大条目第3点“大连湾—金州湾滨海段”与沈大条目第2点“大连城市滨海丘陵”内容重叠。建议合并为一个走廊，仅保留普兰店湾（普兰店海湾特大桥，全长4.96km，哈大高铁唯一跨海湾大桥）等不重复点位。

# 六、处理建议

1. 上述第二、三章共 13 处坐标 / 归属问题，建议在上线前据权威底图逐项修正；其中芒砀山、金鸡岭、瓦屋山、贵港郁江偏移较大，优先处理。

2. 第四章 2 处可见性失实点，建议按文档自身“坐这趟车真的能看到吗”原则降级或删除。

3. 第五章重复条目合并。

4. 其余已标“约 / 推断 / 存疑”的点位（如霞浦、太姥山、丰头河等）维持原口径，按文档计划实乘核验即可。
