# 人数构成 → 目的地形态规则

> 这是本 Skill 最有价值的一条经验规则：**同样的天数与预算，人数构成不同，正确答案完全不同**。
> 违反这里得出的"正确答案"，是新手攻略最常见的事故源。

| 构成              | 推荐形态                                                                                                    | 明确不推荐 / 必须确认                                                                                                  |
| --------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 单人              | 自由行友好：公共交通成熟、青旅/拼车文化成熟、治安好的城市与轻量级自然目的地；可接受"拼小团"参加体验项                                            | ⛔ **不主动推荐需包车/报团才能完成的大环线**（青甘大环线、西藏深度、川西长线）。除非用户明确接受拼小团，且必须同时写出拼小团替代路径、利弊与大致人均 |
| 情侣 / 朋友 2—4 人 | 自由行 + 局部包车/租车；高铁圈邻城深度                                                                                 | 高原长线须确认驾驶经验与晕车耐受                                                                                              |
| 家庭带儿童 / 带老人   | 单基点少换宿、车程短、医疗便利、景区设施完善；可包车                                                                            | 高海拔、长车程、高强度徒步须显著提示                                                                                            |
| 一家三代 / 全家出动   | **独立成团（包车/包团）方案**：一大家子包一辆车/一个团，行程自定义、节奏自控。必须把"包团 vs 散拼"的价格与利弊列清楚                                     | 散拼团人员随机、节奏不可控，需明示                                                                                              |

## 落地要求

1. **"一家人站满团"落地为独立成团选项**：预算允许时，包车/包团对家庭是体验与自由度的最优解。
   方案里必须给出包车日均价区间，**标估算来源与查询时间**。
2. **独行者的替代路径不可省略**：如果用户坚持想去大环线，输出里必须包含
   - 拼小团的具体形式（当地成熟拼团/平台拼车）
   - 利弊（成本分摊 vs 行程自由度下降、陌生人同行）
   - 大致人均增价
3. **任何"不推荐"都必须给理由**，不许只给结论。规则来自真实旅行事故，不是拍脑袋的偏好。
